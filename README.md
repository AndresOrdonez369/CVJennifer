# Portafolio Web

Página web tipo portafolio desarrollada por **Andrés Ordóñez**.

Sitio personal construido con Next.js, React y Tailwind CSS, pensado para presentar de forma clara y elegante el perfil profesional, los proyectos y la información de contacto.

---

## Secciones del sitio

### 1. Hero
Pantalla inicial con nombre, rol profesional y un eslogan corto. Da la primera impresión y comunica de forma directa la propuesta de valor.

### 2. Contact Bar
Barra horizontal justo debajo del Hero con los datos rápidos de contacto (email, teléfono, ubicación) y enlaces a redes sociales para que el visitante pueda comunicarse en un click.

### 3. About Me
Resumen personal con la trayectoria, enfoque profesional y métricas destacadas (años de experiencia, logros clave, alcance del trabajo). Incluye también los idiomas que se manejan.

### 4. Experience
Línea de tiempo con la experiencia laboral. Cada entrada muestra el período, el cargo, la empresa y una breve descripción del impacto generado.

### 5. Education & Skills
Dos bloques combinados: a la izquierda la formación académica (universidad, programa, año), y a la derecha una cuadrícula con las habilidades clave y su nivel de dominio.

### 6. My Projects
Galería de proyectos destacados en formato de tarjetas. Cada tarjeta se puede abrir para ver una página de detalle con:
- Categoría, año e institución
- Imagen ampliada del proyecto
- Descripción extendida
- Highlights / detalles clave
- Espacio para video (cuando aplica)
- Enlaces externos relacionados

### 7. Contact Me
Sección de cierre con una imagen visual de impacto y un formulario funcional para enviar mensajes directamente, además de los enlaces a redes y datos de contacto.

### 8. Header & Footer
- **Header**: logo de marca y botón para descargar el CV en PDF.
- **Footer**: cierre del sitio con logo, créditos y email de contacto.

---

## Stack tecnológico

- **Next.js** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui** para componentes base

---

## Cómo correr el proyecto en local

```bash
cd package
npm install
npm run dev
```

Luego abrir [http://localhost:3000](http://localhost:3000) en el navegador.
